MCP

Appium is the open-source standard for cross-platform automation — one API for Android, iOS, Windows, macOS, and the web. Battle-tested for over a decade.

Appium MCP exposes that engine as a Model Context Protocol server — 15 structured tools that let any LLM perceive screens, locate elements, and drive real devices natively.

The 7 Principles behind AppClaw.

Principle What it does
Negative Example Cache
 Track failures per screen — never repeat same mistake
Progressive Rule Disclosure
 Load rules just-in-time, not all at once
Adaptive Context Budget
 Scale prompt size to screen complexity
Episodic Memory
 Learn from past runs via trajectory store
Few-Shot Trajectories
 Inject one golden example — show, don't tell
Rolling Summarization
 Compress old steps, keep recent in full detail
Screen Fingerprinting
 "This is a login screen" — anchor all reasoning
